# עדכון אופליין - מאגר ספרים

תוכנת שולחן עבודה (Windows ו-macOS, Flutter) שמעדכנת את מאגר הספרים
[YairDaniel11/Otzarya-Unofficial-Books](https://github.com/YairDaniel11/Otzarya-Unofficial-Books)
במחשבים שאינם מחוברים לרשת.

## מה התוכנה עושה

שני מצבים:

1. **מחשב מחובר** - מורידה את המאגר מ-GitHub וממזגת אותו לקובץ PAK יחיד
   (`OtzariaBooks.pak`, נשמר ליד התוכנה). בהרצה חוזרת נכתבים רק קבצים חדשים או ששונו.
2. **מחשב חסום** - מעבירים אליו את התוכנה וקובץ ה-PAK (למשל בדיסק-און-קי), והתוכנה
   מחלצת ממנו את הספרים לתיקיית היעד.

## למה PAK יחיד

המאגר מורכב מזיפים מקוננים עם כפילויות. ה-PAK שומר כל קובץ בנפרד, דחוס, פעם אחת בלבד
(זיהוי לפי גודל ו-CRC), ולכן תופס הרבה פחות מקום, ועדכון מוסיף רק את השינויים.
האינדקס נמצא בסוף הקובץ והכותרת מוחלפת אחרונה, כך שהפסקה באמצע כתיבה לא משחיתה את
המצב הקודם. פעולת "דחיסה מחדש" (compact) מסירה בלוקים מתים.

## שימוש

- במחשב מחובר: פתחו את התוכנה, בחרו הורדה, והמתינו לסיום. קובץ ה-PAK יופיע ליד התוכנה.
- במחשב חסום: העתיקו את התוכנה ואת `OtzariaBooks.pak`, בחרו חילוץ ואת תיקיית היעד.
  קבצים זהים שכבר קיימים ביעד מדולגים.

## בנייה מקומית

```
flutter pub get
flutter test
flutter build windows --release   # או: flutter build macos --release
```

## GitHub Actions

הקובץ `.github/workflows/build.yml` רץ ב-`workflow_dispatch` וב-push של תג `v*`.
הוא בונה ל-Windows ול-macOS, מריץ ניתוח ובדיקות, ומעלה artifacts:
`BooksOfflineUpdate-windows.zip` ו-`BooksOfflineUpdate-macos.zip`. בריצת תג נוצר גם GitHub Release
עם שני הזיפים.

## הערה ל-Mac

האפליקציה אינה חתומה, ולכן בפעם הראשונה Gatekeeper יתריע: קליק ימני על האפליקציה
← **פתח** ← אישור. אם הורדתם את האפליקציה מהדפדפן, macOS עלולה להריץ אותה ממיקום זמני
(App Translocation), ואז "ליד התוכנה" אינו המקום הנכון. העבירו את התיקייה לדיסק או לתיקייה
רגילה (לא ישירות מהורדות), או השתמשו ב"שנה מיקום" בהגדרות התוכנה.
ה-sandbox כבוי בכוונה כדי שהתוכנה תוכל לכתוב ליד עצמה ולבחור תיקיות.

## מגבלות

- zip64 אינו נתמך; נתמכות רק שיטות דחיסה stored ו-deflate.
- התוכנה אינה חתומה (Windows SmartScreen ו-macOS Gatekeeper עשויים להתריע).
- ללא חיבור לרשת אי אפשר להוריד; יש להכין את ה-PAK במחשב מחובר.
